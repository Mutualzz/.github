## Where to start

Everything lives in the **[mutualzz](https://git.mutualzz.com/mutualzz/mutualzz)** monorepo. The other repos are its submodules.

```bash
git clone --recurse-submodules https://git.mutualzz.com/mutualzz/mutualzz.git
```

| Area | Repos |
|---|---|
| **Apps** | `app` · `client` · `mobile` · `server` · `voice` · `updater` |
| **UI** | `ui-core` · `ui-web` · `ui-native` · `themes` · `color-picker` · `contexify` |
| **Shared** | `types` · `validators` · `logger` · `i18n` · `bitfield` · `eslint-config` |
| **Integrations** | `rpc` · `rpc-cpp` · `rpc-csharp` · `mc-bridge` · `mc-voice` |

## Contributing

1. Sign in to [git.mutualzz.com](https://git.mutualzz.com) with your GitHub account. No new account or password needed.
2. Fork the repo you want to change there and open a pull request.
3. Found a bug? [Open an issue](https://git.mutualzz.com/mutualzz/mutualzz/issues/new).

Issues and pull requests opened on GitHub are not monitored.
